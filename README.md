# نظام توزيع المذكرات

تطبيق ويب (عربي بالكامل، RTL) لإدارة دورة توزيع المذكرات التعليمية من المطبعة حتى السنتر/المكتب، مع المخزون والحسابات ونقطة بيع المكتبة.

## المميزات

- **المخزون**: المذكرات (تكلفة/بيع)، المخزن المركزي، الاستلام من المطابع.
- **التوزيع**: تيمات تحمل عُهدة (بدون حسابات مالية)، تسليم للسناتر بالأجل، مرتجعات.
- **الحسابات**: كشف حساب لكل سنتر، تحصيل (كاش/تحويل مع رقم العملية)، مديونيات.
- **المكتبة**: نقطة بيع مباشر (POS).
- **التقارير**: أكثر المذكرات توزيعاً، المديونيات حسب المحافظة، ملخص مالي.
- **الصلاحيات**: مدير، أمين مخزن، تيم، سنتر، كاشير.

## التقنيات

Next.js 16 (App Router) · TypeScript · Tailwind CSS · Prisma · SQLite

## التشغيل محلياً

```bash
npm install
npx prisma migrate dev      # إنشاء قاعدة البيانات
npm run seed                # بيانات أولية + مستخدم مدير
npm run dev                 # http://localhost:3000
```

## حسابات الدخول الافتراضية (من الـ seed)

| الصلاحية | اسم المستخدم | كلمة المرور |
| --- | --- | --- |
| مدير النظام | `admin` | `admin123` |
| أمين المخزن | `store` | `store123` |
| كاشير المكتبة | `cashier` | `cashier123` |

> غيّر كلمات المرور من صفحة "المستخدمون" بعد أول دخول.
